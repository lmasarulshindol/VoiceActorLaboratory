# 偽りの剣士 ― セリフ集

## キャラクター設定

| 項目 | 内容 |
|---|---|
| 名前 | （未設定 ― 演者の解釈に委ねる） |
| 外見 | 逆立った金髪、青く光る瞳、やや小柄で引き締まった体格 |
| 武器 | 身の丈ほどの大剣（亡き親友の形見） |
| 一人称 | 「俺」（全編通して） |
| 口調 | 序盤はクールで突き放すような短文。本来の自分を取り戻した後は少し柔らかく、不器用で朴訥とした話し方に変わる。 |
| 性格 | 表面上はクールな元エリート傭兵。実際は内気で人付き合いが苦手な青年。記憶の混濁により他者の経歴を自分のものと思い込んでいる。自分の弱さを受け入れることで、本当の強さに辿り着く。 |

| 区分 | 偽りの人格（序盤） | 本来の自分（後半） |
|---|---|---|
| 態度 | クール・無関心・皮肉屋 | 内気・不器用・素直 |
| 口癖 | 「興味ないな」 | 「……わかった」 |
| 戦い方 | 自信に満ちた一匹狼 | 仲間と共に戦う |
| 弱さ | 隠す・見せない | 認める・受け入れる |
| 声のトーン | 低く、抑揚少なめ | 少し高く、感情が滲む |

## 収録メモ

### 演技指針

- **序盤（偽りの人格）**：低く抑えた声。感情を出さない。クールに突き放す。だが時折、不自然な間や動揺が混じる。
- **中盤（崩壊）**：声が震える。息が荒くなる。頭痛の発作では苦しげに。自分を見失う恐怖を全身で表現。
- **後半（本来の自分）**：少しだけ声のトーンが上がる。言い淀み、照れ、不器用さ。でも芯には優しさと決意がある。
- **戦闘**：叫ぶシーンあり。気合と必死さ。英雄的な格好よさではなく、泥臭い全力。
- **罪と赦し**：静かで内省的。自分を責める声。最後にようやく穏やかになる。
