```
【第1層：表面】 天真爛漫・明るい・おしゃべり・花好き

```

## 収録メモ

### 演技指針

- 基本は「太陽のような明るさの裏にある静かな覚悟」。天真爛漫な表面と、運命を知る深さの二層を常に意識する。
- 明るいセリフでも、ほんの一瞬だけ翳りが差す瞬間を作る。笑い声のあとの小さな息など。
- からかうシーンは「悪意のないいたずら」。相手を傷つけない、愛情のある茶目っ気で。
- 星の声に関するシーンは、普段より声のトーンを半音落とし、ゆっくりと。孤独を感じさせつつも、それを受け入れている穏やかさを。
- 戦闘ボイスは「戦い慣れていない」感を残す。掛け声にも日常の明るさが滲み、必殺技の時だけ古代の血が覚醒する荘厳さを。
- 別れのシーンは「泣かせにいかない」演技。本人が一番辛いはずなのに、相手を安心させるために笑っている。その笑顔の奥にある震えを。

### 参考イメージ

| 項目 | 内容 |
|---|---|
| 声質 | 明るく澄んだソプラノ〜メゾソプラノ。芯のある透明感 |
| 話速 | やや早め・弾むようなリズム。感情が深まると自然にゆっくりになる |
| 息遣い | 笑い声と一緒に息が漏れる。走った後のような弾んだ呼吸も特徴 |
| 笑い方 | 「ふふっ」「えへへ」「あっはは」とバリエーション豊か。声を上げて屈託なく笑う |

| 場面 | 表面の演技 | 裏にある感情 |
|---|---|---|
| 日常・花売り | 天真爛漫・おしゃべり | 日常への感謝・失われることへの予感 |

| 戦闘 | 一生懸命・やや不慣れ | 守りたいものがある強さ |
| モノローグ | 素直・飾らない | 本当の自分・一人の少女としての弱さ |
