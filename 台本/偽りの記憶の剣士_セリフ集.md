### 性格の多層構造

```
【第1層：表面】 無関心・クール・「興味ないね」
【第2層：防壁】 偽りの記憶による虚勢・元エリート兵士という仮面
【第3層：本心】 自信のなさ・自分が何者かわからない恐怖
【第4層：核】 不器用な優しさ・仲間への深い愛情・守る意志
```

## 収録メモ

### 演技指針

- 基本は「素っ気なさの奥にある不器用な優しさ」。短い言葉の語尾にさりげない温かみを。
- 「興味ないね」は拒絶ではなく防衛本能。本当は興味があるのに、関わるのが怖い。
- 偽りの記憶を語る時は自信ありげに、でも時折違和感のある「間」を入れる。
- 記憶の崩壊シーンは、頭痛とともに声にノイズが入るイメージ。苦しみながらも耐える。
- 戦闘ボイスは力強く、大剣の重さを感じさせる。掛け声に「重量感」を意識して。
- 乗り物酔いシーンは情けない声で。普段のクールさとのギャップが笑いを生む。

### 参考イメージ

| 項目 | 内容 |
|---|---|
| 声質 | 低めの青年声。クールだが冷たくはない、どこか温もりを残す |
| 話速 | 普段は短く素っ気なく。本音が漏れる時はやや早口になる |
| 息遣い | 動揺すると息が漏れる。記憶の混乱時は荒い呼吸。普段は最小限 |
| 笑い方 | 基本は笑わない。笑う時は小さく「ふっ」と鼻で笑う程度。本当に笑うとぎこちない |

### 演技のレイヤー構造

| 場面 | 表面の演技 | 裏にある感情 |
|---|---|---|
| 日常会話 | 無関心・素っ気ない | 照れ・本当は嬉しい |

| 偽りの記憶 | 自信満々の元エリート | 不安・違和感・恐怖 |

| 戦闘 | 力強い・攻撃的 | 守る意志・覚悟 |
| 独白 | 素直・静か | 自分との和解・希望 |
