**性格・役割（確定分のみ）**

- 優真のことを**心から慕っている**。
- **優真より年下**。年上の優真を「兄様」と呼ぶ。
- 地理的に離れていても、優真への想い・尊敬は変わらない（またはむしろ強い）。
- 呼び方は「兄様」だが、**話し方自体は砕けたタメ口**。敬語（です・ます調、尊敬語・謙譲語）や丁寧語は優真には使わない。
- VoiceStep 公式 Discord 経由で知り合い、**派生個人サーバー**で優真と交流を始めた。

**口調・演技メモ（執筆時のたたき台）**

- 優真の前では **「兄様」＋タメ口** の組み合わせ。
  - OK: 「兄様、今日の練習聞いてよ」「兄様、まだ起きてる？」
  - NG: 「兄様、聞いてもらえますか」「兄様、お疲れ様です」
- 「兄様」は**呼称**であり、**敬語ではない**。慕いは呼び方に込め、文体は親しい仲のまま。
- 「兄様」を自然に口にする（連呼しすぎない。感情が高ぶる場面で効かせる）。
- 一人の場面・第三者への話し方は、執筆時に別途定義。
- **口調サンプル**: 「兄様、今日の練習、聞いてよ……。」

## 二人の関係

### 確定している関係性

```
刹那 ──（慕う・尊敬）──> 優真
         呼称: 「兄様（にいさま）」
         口調: タメ口（敬語・丁寧語なし）

優真 ──（気遣い・指導）──> 刹那
         呼称: 「刹那さん」
```

- 刹那は優真を**「兄様」と呼び、慕っている**。
- 呼称は「兄様」だが、**優真への会話はタメ口**。敬語・丁寧語は使わない。
- 優真は刹那のことを**「刹那さん」**と呼ぶ。
- **血のつながりはない**。「兄様」は慕いの呼称。
- **優真の方が年上**、刹那の方が年下。
- 二人とも**声優の卵**で、**VoiceStep** の参加者同士。
- **優真＝関東、刹那＝北海道**で別々に暮らしている。
- **対面での再会経験はない**（オンラインのみの知り合い）。

### 出会いの経緯

1. 優真・刹那ともに **VoiceStep（ボイスステップ）** — 未経験から声優を始められるプロジェクト — に参加。
2. まず **VoiceStep 公式 Discord サーバー** で関わる（台本練習・雑談・情報交換など）。
3. 公式サーバーから **派生した個人 Discord サーバー** が立ち上がり、そこで二人が知り合う。
4. 以降、演技の練習や日常のやり取りは主に **Discord（テキスト・ボイス）** で続く。
5. **一度も直接会っていない**。声と文字だけが二人の距離をつないでいる。

### 未設定（プロット前に決めるとよい項目）

- 具体的な年齢差（何歳差か）
- 経験値の差（VoiceStep参加時期など）
- 恋愛要素の有無
- 現在の連絡頻度・親密度の具体像
- 派生サーバーを誰が立てたか／他にどんなメンバーがいるか

## Discordサーバーでの会話

二人の交流の**主舞台**。対面していないため、日常も演技練習もほぼここで完結する。

### サーバー構成

| サーバー | 役割 | 二人の関わり方 |
|----------|------|----------------|
| VoiceStep 公式 Discord | 大人数の練習・情報交換・イベント | 最初に参加。互いに直接話すほどではない段階 |
| **派生個人サーバー** | 少人数の練習・雑談 | **知り合いの場。以降の主な交流はここ** |

派生個人サーバー（名称未定）の想定チャンネル例:

| チャンネル | 種別 | 用途 |
|------------|------|------|
| `#雑談` | テキスト | 日常のやり取り、連絡、感想 |
| `#台本` | テキスト | 台本の共有・添削・メモ |
| `#練習` | ボイス | 読み合わせ・演技指導・通話練習 |
| `#録音置き場` | テキスト | 音声ファイルや収録の報告 |

※ チャンネル名・数は執筆時に調整可。台本内では **チャンネル名をト書きで明示** する。

### 会話の種類

#### テキストチャンネル

- 文字のみ。スタンプ・リアクション・画像添付は**使用可**（多用しすぎない）。
- 刹那も優真も、**テキスト上でも口調ルールは同じ**（刹那＝兄様＋タメ口、優真＝刹那さん）。
- 返信が遅れる・既読スルー・入力中…など、**Discord特有の間**も描写してよい。

#### ボイスチャンネル（VC）

- **声優台本の本編は基本ここ**。セリフは音声として収録・演技する。
- 接続・切断、マイクミュート、イヤホン調整、回線不良などの**ト書き**を挟んでよい。
- VC内のセリフは **ボイストランド形式**（`役名：セリフ`）で書く。

### 台本での描き方

#### 基本フォーマット

```
0：Discord ― 派生個人サーバー ― #練習（ボイスチャンネル）
0：刹那がVCに参加する。少し緊張した様子。
刹那：兄様、聞こえる？
優真：刹那さん、ばっちり聞こえてるよ。
```

テキストチャンネルの場合:

```
0：Discord ― 派生個人サーバー ― #雑談（テキスト）
刹那：兄様、今日のオーディション終わった
刹那：……微妙だった
優真：刹那さん、お疲れ。詳しく聞かせてもらえる？
```

#### システム・UI のト書き

Discord の通知や操作は **`0：` ト書き** で表す。

| 描写したいもの | ト書き例 |
|----------------|----------|
| 参加 | `0：刹那が #練習 に参加した` |
| 退出 | `0：優真がVCから退出する` |
| テキスト送信 | `0：刹那が #雑談 にメッセージを送る`（またはセリフ行のみ） |
| 通知音 | `0：Discordの通知音` |
| 通話中の沈黙 | `0：VC内、短い沈黙` |

#### 呼称・口調（Discordでも不変）

| 場面 | 刹那 | 優真 |
|------|------|------|
| テキスト | 兄様＋タメ口 | 刹那さん |
| VC | 兄様＋タメ口 | 刹那さん |

- テキストだからといって、刹那が急に敬語になる**NG**。
- VCでも「刹那さん」「兄様」の呼称ルールは**変わらない**。

### 会話の距離感（参考）

- 刹那は優真がVCにいると、**わざわざ上がっていく**ことが多い。
- 優真は刹那の練習依頼や相談に、**返事を早めに**返すことが多い（未対面ゆえの気遣い）。
- 深夜帯の `#雑談` や `#練習` も自然（関東・北海道とも日本時間）。

### サンプル（テキスト＋VC）

```
0：Discord ― 派生個人サーバー ― #雑談（テキスト）
刹那：兄様、今日の台本送った
優真：刹那さん、見たよ。後半の抑揚、いい感じになってきてるね。
刹那：ほんと？　兄様が前に言ってたとこ、意識してみた
優真：うん。じゃあ #練習 で一回読もうか。

0：Discord ― #練習（ボイス）。優真がすでに接続中。
0：刹那がVCに参加する。
刹那：兄様、聞こえる？
優真：刹那さん、聞こえてる。じゃあ、さっきの続きから。
```

## 台本執筆ルール

### フォーマット

本プロジェクトの台本は、必要に応じて **ボイストランド形式** に従う。

- セリフ: `役名：セリフ`
- ト書き: `0：説明`
- **Discord シーン**: チャンネル名・種別（テキスト／VC）をト書きで明示（詳細は「Discordサーバーでの会話」）
- 詳細: ワークスペース `.cursor/commands/ボイストランド_台本ガイドライン.md`

### 役名表記

| キャラ | 台本での表記（統一） |
|--------|----------------------|
| 優真 | `優真` |
| 刹那 | `刹那` |

- 1台本内で表記ゆれを出さない（「ゆうま」「セツナ」等に混在させない）。

### 優真の呼称

- 優真が刹那に話しかけるとき、**「刹那さん」** を使う。
- 「刹那」「せつな」等への表記ゆれは出さない。

### 刹那の呼称・口調

- 刹那が優真に話しかけるとき、**「兄様」** を使う場面を適宜入れる。
- 毎セリフ必須ではない。感情・場面に応じて自然に。
- 優真へのセリフは**タメ口**に統一する。です・ます調、〜ください、お〜、いただく 等の敬語・丁寧語は**使わない**。

### NG・注意（デフォルト）

- 設定にないキャラの突然の登場（必要なら本ファイルを先に更新）
- 時代設定の矛盾（現代日本から外れる描写）
- 刹那が優真を「兄様」以外の敬称だけで通す長尺（キャラの核を崩す）
- **刹那が優真に敬語・丁寧語を使うセリフ**（「兄様、ありがとうございます」等）
- **対面済みの描写を無断で追加する**（初対面シーンは設定更新またはプロット上の大イベントとして扱う）

## シーンの種類（参考）

距離がある二人向けの台本アイデア例（採用は任意）:

1. **Discord 通話練習** — 台本読み合わせ、感情の入れ方の相談
