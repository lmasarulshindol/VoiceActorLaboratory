# プロット集 — 恋愛バトルコメディー（10分台本用）

---

## プロット1：「告白バトルロイヤル ～先に好きって言ったら負け～」

### ジャンル
ラブコメ × 心理戦

### 登場人物（2〜3名）
- **蒼葉ユウキ**（男性・高校生）：クール系だが内心パニック持ち。好きな相手にだけ早口になる癖がある。一人称「俺」。
- **桜庭ヒナ**（女性・高校生）：天然に見せかけた策士。笑顔の裏で常に勝ち筋を計算している。一人称「あたし」。
- **ナレーション**（中性）：二人の心理戦を実況するスポーツ中継風の語り。

### あらすじ
放課後の教室。ユウキとヒナは互いに好意を持っているが、「先に告白した方が負け」という謎のプライド合戦に突入している。二人は会話の中で相手に告白させようと、あの手この手で揺さぶりをかける。「好き」という単語を会話に紛れ込ませるトラップ、わざと距離を詰める心理戦、第三者の存在をチラつかせるブラフ——しかし互いに手の内を読み合い、決定打が出ない。最終的にヒナが仕掛けた「じゃあ明日から別の人と帰る」ブラフに、ユウキが耐えきれず「……好きだから、やめろ」とポロッと漏らしてしまう。勝ち誇るヒナだが、直後に「……あたしも、好き」と赤面して言い返す。ナレーションが「両者リングアウト！ 引き分けです！」と締める。

### 見どころ・演技ポイント
- 平静を装う声と、内心の焦りのギャップ演技
- ナレーションの実況テンションの緩急
- ラスト「好きだから、やめろ」の不意打ち感ある本音の漏れ方
- 10分の中で心理戦のテンポを上げていく構成

### 想定シーン数
4〜5シーン（放課後の教室 → 心理戦フェーズ1〜3 → 決着）

## プロット2：「勇者と魔王の婚活クエスト ～世界を救うより難しい～」

### ジャンル
ファンタジーラブコメ × パロディ

### 登場人物（2〜3名）
- **勇者レオン**（男性・20代）：正義感は強いが恋愛偏差値3。剣で魔物は倒せるが女性との会話で即死する。一人称「僕」。
- **魔王サリエル**（女性・年齢不詳）：威厳あるが人間界の文化に異常に詳しい。恋愛漫画を100冊読んで「人間の恋愛」を完全に誤解している。一人称「我」→照れると「わ、私」。
- **ナレーション**（RPG風）：クエスト進行を告げるシステムボイス風。

### あらすじ
魔王を倒しに来た勇者レオンだが、魔王サリエルの第一声が「我と結婚せよ」。困惑するレオンに、サリエルは「恋愛漫画によると、敵同士の恋は最も燃えるらしい」と力説。レオンは断るが、サリエルが「では恋愛クエストで勝負だ。我が先にお前を落としたら結婚、お前が勝ったら世界を解放してやる」と提案。クエスト内容は「手をつないで10秒耐える」「壁ドンを成功させる」「夕日をバックに告白する」など、恋愛漫画から引用したミッション。二人とも照れて全くクリアできず、グダグダになるが、最後に「もう一回……やり直しても、いいか？」「べ、別に勝負のためだからな！」と、いつの間にか本気の距離感になっている。

### 見どころ・演技ポイント
- 魔王の威厳ある声と照れた声の落差
- 勇者の「強い男」演技が恋愛場面で完全崩壊するギャップ
- RPGシステムメッセージ風ナレーションのシュールさ
- 壁ドンチャレンジで二人とも固まるシーンの間の演技

### 想定シーン数
5シーン（魔王城対面 → プロポーズ → クエスト開始 → 壁ドン＆手つなぎチャレンジ → 夕日エンド）

## プロット3：「恋のスマッシュ！ ～テニス部の告白ラリー～」

### ジャンル
スポーツラブコメ × 青春

### 登場人物（2名）
- **日向アキラ**（男性・高校生）：テニス部エース。コートの上では無敵だが、好きな女子の前では急にサーブが入らなくなる。一人称「俺」。熱血だが不器用。
- **瀬戸カナデ**（女性・高校生）：女子テニス部のキャプテン。負けず嫌いで、何事も勝負で決めたがる。一人称「私」。強気だが好きな相手の前だと空振りする。

### あらすじ
テニス部の男女合同練習日。アキラとカナデはお互いを意識しているが、素直になれない。カナデが「私に勝ったら何でも一つ言うこと聞いてあげる」と勝負を持ちかけ、アキラは内心（告白のチャンスだ！）と奮い立つ。しかし試合が始まると、カナデのスコートが気になってサーブが入らない、アキラの腕まくりを見てカナデがリターンミス——と、お互い恋愛脳が邪魔をして史上最低レベルの試合に。周囲のテニス部員たち（モブ・心の声として処理）が「あれは恋のダブルフォルトだ……」と実況。最後、タイブレークで二人が同時にネット際に走り、ぶつかって転倒。至近距離で目が合い、アキラが「お前に勝ったら……デートしてくれ」、カナデが「……勝たなくても、してあげる」。

### 見どころ・演技ポイント
- スポーツの熱量と恋愛の照れが交互に来るテンポ感
- 打球音やスニーカーの音を声で表現する遊び
- 至近距離での息づかい演技
- カナデの強気キャラが崩れる瞬間の声の揺れ

### 想定シーン数
4シーン（合同練習・挑発 → 試合前半・グダグダ → 試合後半・加速 → ネット際の決着）

## プロット4：「元カレVS今カレ ～審判は本人～」

### ジャンル
三角関係コメディ × 修羅場ギャグ

### 登場人物（3名）
- **九条ソウマ**（男性・20代社会人）：現在の彼氏。穏やかな性格だが、怒ると敬語が丁寧になる危険なタイプ。一人称「僕」。料理が得意。
- **鷹宮レン**（男性・20代社会人）：元カレ。チャラそうに見えて一途。未練を隠さないストレートな性格。一人称「俺」。顔がいいのが唯一にして最大の武器。
- **橘ミオ**（女性・20代社会人）：二人の間で板挟み。しっかり者だがこの状況だけは処理能力オーバー。一人称「私」。ツッコミ担当。

### あらすじ
ミオが彼氏のソウマとカフェでデート中、偶然元カレのレンが来店。気まずい空気の中、レンがソウマの隣に座り「よっ、後輩くん。彼女を幸せにできてる？」と挑発。ソウマは笑顔で「ええ、おかげさまで。先輩の反面教師があったので」と返す。ミオのことそっちのけで二人のマウント合戦が始まる——「俺の時はこう言って喜んでた」「今の彼女はもっと笑ってますよ」「手料理より外食のセンスだろ」「手料理を喜ばない人はそうでしょうね」。ミオが「私の話してるのに私が蚊帳の外なんだけど！？」とブチ切れて仲裁。最終的に「二人ともウザい。でも……ソウマ、帰ろ」と手を引く。レンが「……ちぇ、負けたわ」と笑う。

### 見どころ・演技ポイント
- ソウマの笑顔の圧と敬語マウントの怖さ
- レンのチャラさの中に見える本気の未練
- ミオが振り回される→ブチ切れる→デレるの三段活用
- 三者三様の声色の使い分けが試される構成
- レンの最後の「負けたわ」の爽やかさ

### 想定シーン数
5シーン（デート中 → レン登場・対面 → マウント合戦前半 → マウント合戦後半＆ミオ爆発 → 決着・退場）

## プロット5：「配信中に告白してしまった件 ～コメント欄が修羅場～」

### ジャンル
現代ラブコメ × ネット配信パロディ

### 登場人物（2名＋コメント欄）
- **夜宵ルカ / 本名:陸（りく）**（男性・20代）：ゲーム配信者。登録者10万人の中堅VTuber。配信中はハイテンションだが、素は人見知り。一人称「俺」（配信中）/「僕」（素）。
- **星川ノア / 本名:希（のぞみ）**（女性・20代）：ルカと同じ事務所のVTuber。歌枠が人気。甘え上手に見えて実はルカより肝が据わっている。一人称「ノア」（配信中）/「私」（素）。
- **コメント欄**（SE・ナレーション的処理）：視聴者のコメントを読み上げる形で「草」「告ったwww」「切り抜き確定」などの反応を入れる。

### あらすじ
ルカとノアの初コラボ配信。ゲーム対決企画で盛り上がる中、罰ゲームとして「本音トークタイム」が発動。お互いの第一印象を聞かれ、ルカが調子に乗って「最初から可愛いと思ってた」とポロリ。コメント欄が爆発。ルカはキャラ設定（クール系）を守ろうと「いや、あれは配信用の……」と取り繕うが、ノアが「へぇ〜、じゃあ今のは嘘なんだ？」と攻める。追い詰められたルカが素の声で「……嘘じゃない」と言ってしまい、コメント欄が「素の声出てる」「ガチじゃん」と大騒ぎ。ノアが配信を切って（ブツッ）、素の声で「……私も、ずっと好きだった」。エンドカードのSEが流れ、二人だけの空間になる。

### 見どころ・演技ポイント
- 配信用の声（ハイテンション）と素の声（小さく本音）の切り替え
- コメント読み上げのテンポとツッコミ機能
- 「配信を切る」瞬間の空気の変化
- VTuberあるあるネタを散りばめたリアリティ
- ノアの「甘え声」と「ガチの告白声」の使い分け

### 想定シーン数
4シーン（配信スタート・ゲーム対決 → 罰ゲームトーク → ルカの本音漏れ・コメント炎上 → 配信OFF後の二人）

# 制作メモ

- 各プロット共通で **10分前後**（原稿用紙換算で約15〜20枚）を想定
- 掛け合い台本として起こす場合は、シーン区切りに `---` を挿入し、ト書き `（）` で演技指示を補足
- コメディ要素はテンポ重視、恋愛要素はテンポを落として「間」で聴かせる
- いずれもラストは甘い着地にし、聴き終わりの満足感を確保
