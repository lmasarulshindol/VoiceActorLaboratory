# 氷の剣士 ― セリフ集

## キャラクター設定

| 項目 | 内容 |
|---|---|
| 名前 | （未設定 ― 演者の解釈に委ねる） |
| 外見 | 紫がかった黒髪のショートヘア、鋭い目つき、華奢だが引き締まった体躯、黒を基調とした軍服風の衣装 |
| 武器 | 細身の長剣（片手剣）。剣に強い執着を持つ |
| 年齢 | 16歳 |
| 一人称 | 「俺」 |
| 口調 | 基本的に冷淡で素っ気ない。年齢に不釣り合いなほど大人びた言い回し。照れると早口になる。怒ると低く静かになる。 |
| 性格 | 天才剣士ゆえの傲慢さと、孤独な少年の脆さが同居する。表面は刺々しいが、根は義理堅く情に厚い。素直になれない不器用さが最大の特徴。自分の弱さを絶対に見せまいとする虚勢と、本当は仲間を求めている渇望の間で常に揺れている。 |

### 性格の多層構造

```
【第1層：表面】 冷徹・尊大・毒舌・他者を突き放す
【第2層：防壁】 虚勢・強がり・感情の否定
【第3層：本心】 孤独・不安・誰かに認められたい渇望
【第4層：核】 不器用な優しさ・自己犠牲的な誠実さ
```

## 収録メモ

### 演技指針

- 基本は「刺々しさの奥にある優しさ」。冷たい言葉の語尾に、微かな温もりを宿す。
- ツンデレの「ツン」は攻撃的ではなく防御的。傷つくのが怖いから突き放す。
- 照れた時は声が少し上ずり、早口になる。普段の冷静さが崩れる瞬間を大切に。
- 戦闘ボイスは鋭く、全身のバネを感じさせる。瀕死時は呼吸が乱れ、それでも意志が折れない。
- 「……」の間には感情の葛藤がある。言いかけてやめる、その沈黙に本心が滲む。
- 独白シーンは素の声。普段の仮面を外した、16歳の少年の声で。

### 参考イメージ

| 項目 | 内容 |
|---|---|
| 声質 | 少年と青年の境目。低めだが若さが残る |
| 話速 | 普段はやや早め・素っ気ない。感情が動くと遅くなったり早くなったりムラが出る |
| 息遣い | 照れた時・動揺した時に息が漏れる。普段は最小限 |
| 舌打ち | 「ちっ」は頻出。苛立ちではなく照れ隠しのサイン |

### 演技のレイヤー構造

| 場面 | 表面の演技 | 裏にある感情 |
|---|---|---|
| 日常会話 | 冷淡・突き放し | 本当は嬉しい・照れている |
| 仲間との会話 | 強がり・毒舌 | 信頼・感謝・恐れ |
| 戦闘 | 鋭い・攻撃的 | 守る意志・覚悟 |
| 独白 | 素直・静か | 孤独・渇望・後悔 |
| 瀕死・最期 | 力なく・穏やか | 解放・感謝・受容 |
