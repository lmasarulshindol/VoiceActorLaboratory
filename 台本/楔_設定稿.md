## 1. 世界背景

聞き手に伝えるのはこれだけ。

1. 塔の上で魔物が目覚めかけている。降りてくれば、ふもとの村が滅びる
2. 一年前、朔は誰にも言わず、一人で魔物に挑み、負けた
3. 魔物の欠片が黒い石になって黒曜の鍔に食い込み、朔の心を縛っている。朔は意識を保ったまま、魔物の門番にされている
4. 石を砕けば、朔は解放される

## 2. 人物設定

### 主人公｜蒼井 カイ（あおい かい）／CV: Akira

| 項目 | 内容 |
|---|---|
| 年齢 | 22 |
| 声の設計 | 序盤は困惑で言葉が詰まる。中盤で感情を叩きつけ、終盤は静かに決まっている |
| 武器 | 片刃の長剣。朔から譲られた |
| 一人称／二人称 | 俺／師匠 |

**性格の核**
- 嘘が下手で、思ったことが先に口から出る
- 幼い頃に朔に拾われ、塔のふもとの村で育った
- 一年前に朔が消えたことを「捨てられた」と受け止め、その棘をずっと抱えている
- 朔に習ったのは斬る技だけ。朔が消えてから、一人で突きを磨いた

**感情の流れ**
1. 門前の人影が朔だと分かり、安堵する
2. 朔が魔物の番人だと言い、意味が分からず困惑する
3. 一年分の怒りと寂しさをぶつける
4. 一瞬漏れた朔本人の声に、何かがおかしいと気づく
5. 朔が一人で魔物に挑んでいたと知り、怒りの向きが変わる。「なんで一人で行ったんだよ」
6. 「師匠を連れ戻す」と決め、教わっていない突きで黒い石を砕く

## 4. 物語の流れ（約7分）

### 場1｜門前（約1分）
- 師匠だと気づいて駆け寄るカイ。朔は冷たい声で「下がれ」
- 剣を抜く音に、黒い唸りが混じる
- 朔は魔物を「あのお方」と呼ぶ。カイには意味が分からない

### 場2｜問い（約1分30秒）
- カイが一年分の怒りをぶつける
- カイ「退いてくれ。師匠とだけは戦いたくない」
- 唸りが弱まり、朔本人の声が漏れる。「逃げろ」「戦いたくない、お前とは」
- 唸りが戻り、「通さん」。カイは剣を抜くしかない

### 場3｜第一合（約1分）
- 同じ技・灯閃で相殺（朔の光は黒く濁っている）
- 朔は門の前から一歩も動かずにカイをあしらう
- 朔が振り下ろした刃が、カイの喉元で震えて止まる。本人が、自分の手を止めた

### 場4｜黒い石（約1分30秒）
- カイが戦い方を変え、朔を門の扉まで押し込む
- 鍔迫り合いの距離で、カイが鍔の黒い石に気づく
- 朔本人が出てきて語る。一年前に一人で挑んで負けたこと。石を砕けと
- カイ「なんで一人で行ったんだよ！」
- 朔は門を離れて前へ出る。カイ「俺が師匠を連れ戻す」

### 場5｜剣戟（約1分30秒）
- 技名の叫び合い
- 光の刃の壁を、カイが正面から抜ける
- 突き「星穿ち」で鍔の黒い石を砕く

### 場6｜解放（約1分）
- 朔「……静かだ。頭の中が、一年ぶりに静かだ」
- 「突きは、一人で覚えた。師匠がいなくなってから」
- 朔「行くな。あいつは強い。私でも勝てなかった」／カイ「知ってる。だから、師匠を越えてきた」
- カイ「行ってくる。終わったら、一年分の話、全部聞かせてもらうからな」。門をくぐる

### 場7｜余韻（約30秒）
- 塔の上から魔物の咆哮と、カイの「灯閃——！」。朔が最初に教えた技
- 朔が黒曜を拾って立ち上がり、「……死ぬなよ、カイ」
- 石段を上っていく朔の足音で終わる。後を追って加勢に向かう

## 5. 戦闘の設計

### 舞台：第三門前の踊り場

- 円形の石の踊り場。端から端まで二十歩ほど
- 片側に門。人の背丈三人分の鉄の扉
- 反対側は、カイが上ってきた石段
- 周りは吹きさらし。縁に腰の高さの石の欄干。強い風が絶えず鳴っている

### 二人の戦い方

| | カイ | 朔 |
|---|---|---|
| 武器 | 片刃の長剣。軽い | 両手剣「黒曜」。重く、長い |
| 戦い方 | 足で回り込み、手数で崩す | 足を止めて中心を取り、間合いの長さで寄せつけない |
| 番人としての構え | ― | **門を背にして、一歩も動かない** |
| 技の系統 | 朔から習ったのは斬る技だけ。**突きは独学** | 斬る技しか持たない。突きは読めない |
| 癖・弱点 | 力むと振りが大きくなり、脇が空く。押し合いでは体重負けする | 大技のあと、剣を構え直すのに一拍かかる。鍔の黒い石 |

### 音だけで動きを伝える原則

1. 動きは効果音と、**相手の反応**で伝える（「上か」「動いたな」）。自分の動きを自分で説明させない
2. **朔が一歩も動かない → 下がらされる → 門を離れて自分から前へ出る**。この変化を戦いの優劣の目盛りにする
3. 指導のセリフは、誰が聞いても分かる体の言葉だけ使う（振りが大きい、脇が空いている、軽い）
4. **刀身の黒い唸りの強弱**で、朔のどちらの声が出ているかを伝える

### 場3の動き

1. 朔の**灯閃**（黒く濁った光の弧）と、カイの**灯閃**（白い光の弧）が真ん中でぶつかって弾ける
2. カイは懐へ入り、正面から打ち込む。朔は剣の腹で受け、体重で押し返す
3. カイが右へ回り込んで三連撃。朔は足を動かさず、剣の向きを変えるだけで全部受ける
4. カイが大きく振りかぶる。朔は柄頭でカイの脇腹を突き、カイは石床を転がる
5. 朔が倒れたカイに黒曜を振り下ろす。刃がカイの喉元の手前で震えて止まる。本人の意志が、魔物に逆らって止めた

### 場4の動き

1. カイが大振りをやめ、小さく速い斬撃を左右から続ける。朔の受けが少しずつ遅れる
2. 朔が初めて半歩下がる。カイ「動いたな、師匠！」
3. さらに押し込み、朔の背が門の鉄扉に当たって鳴る。鍔迫り合い
4. 至近距離で、カイが鍔元の脈打つ黒い石に気づく。唸りが弱まり、朔本人が語る
5. 唸りが跳ね上がり、朔がカイを突き放す
6. 朔が自分から門の前を離れて歩み出る

### 場5の動き

1. カイの**星雨突き**。間合いの外から一気に踏み込み、光をまとった突きを雨のように連打する。一つが朔の肩をかすめる
2. 朔の**山割り**。真上から一直線に振り下ろし、突きの連打をまとめて叩き落とす。カイの剣ごと石床に押しつける
3. 朔の**地鳴り落とし**。高く跳び、着地と同時に黒曜で床を叩き割る。カイは欄干まで吹き飛ぶ
4. 本人の声で「立つな」。カイは立つ
5. 朔の**終焉の守人**。黒曜を床に深く突き立てると、黒い光の刃が何十本も立ち並び、近づく者を斬る壁になる
6. カイは避けずに正面から壁へ走り込み、斬られながら抜ける
7. 抜けた先は朔の目の前。朔は床から黒曜を引き抜くのに一拍かかる。朔は突きの構えを読めない
8. カイの**星穿ち**。切っ先に光を一点に集めた一直線の突きで、鍔元の黒い石を貫いて砕く。朔の体には当てない

### 技名一覧

| 使い手 | 技名 | 読み | 動き |
|---|---|---|---|
| 両者 | 灯閃 | とうせん | 踏み込みながら横一文字に振り抜く。刃に灯った光が弧になって飛ぶ。朔が最初に教えた技。場7の魔物戦でも使う |
| カイ | 星雨突き | ほしさめづき | 間合いの外から踏み込み、光をまとった突きを雨のように連打する |
| カイ | 星穿ち | ほしうがち | 切っ先に光を一点に集めた一直線の突き。朔が教えていない、カイだけの奥義 |
| 朔 | 山割り | やまわり | 真上から一直線に振り下ろす重い一閃 |
| 朔 | 地鳴り落とし | じなりおとし | 高く跳び、着地と同時に剣で床を叩き割る |
| 朔 | 終焉の守人 | しゅうえんのもりびと | 剣を床に突き立て、黒い光の刃の壁を立てる。番人にされた朔の奥義 |

命名の方針：
- 技名に剣の名前を入れない
- 朔が教えた技は「灯」、カイが一人で作った突きは「星」、朔自身の技は「山・地」で揃える

音声合成では読みが揺れやすいので、試聴して読みを確認する。
