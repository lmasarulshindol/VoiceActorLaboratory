## キャラクター設定

| 項目 | 内容 |
|---|---|
| 名前 | （未設定 ― 演者の解釈に委ねる） |
| 外見 | 黒髪のポニーテール、鋭く熱のない瞳、長身。左右で柄の違う羽織（亡き姉と親友の形見） |
| 武器 | 青く染まった刀。受けの剣を極めた流儀 |
| 一人称 | 「俺」 |

### 二面性の構造

| 区分 | 表層 | 本質 |
|---|---|---|
| 態度 | 冷たい・無愛想・無表情 | 情が厚い・傷つきやすい・責任感が強い |
| 言葉 | 短く切る・説明しない | 言いたいことをうまく言えないだけ |
| 自己評価 | 「俺はお前たちとは違う」 | 「俺はお前たちほど強くない」の意味 |
| 戦い方 | 静・受け・無駄のない剣 | 守りたい者のために本気を出す |
| 声のトーン | 低く平坦。感情を乗せない | 感情が溢れる瞬間は一気に熱が乗る |

## 収録メモ

### 演技指針

- **基本**：低く平坦。抑揚をほぼつけない。感情を「乗せない」ことが最大の個性。
- **短文・間**：一文が短い。「……」の沈黙が言葉以上に語る。急がない。
- **誤解セリフ**：ぶっきらぼうに言い切る。言い直さない。言い直すと余計に下手になる。
- **優しさの瞬間**：声の高さはほぼ変えない。ただし言葉の選び方と間で温度を出す。
- **自責・過去**：声量が落ちる。息が少し沈む。泣きは抑え込む方向。
- **本気の戦闘**：一気に熱が乗る。普段との落差が重要。叫ぶというより、静かな怒りの延長。
- **「凪」**：ほぼ囁き。空気が止まるような静けさで。

### 参考イメージ

| 項目 | 内容 |
|---|---|
| 声質 | 中低音。澄んでいて、熱を感じさせない |
| 話速 | 遅い。余分な語尾を削る |
| 間 | 「……」を多めに。沈黙で圧と孤独を出す |
| 感情の出し方 | 爆発させない。滲ませるか、一瞬だけ漏れる |
| 笑い方 | ほぼ笑わない。笑っても「……ふっ」と短く、すぐ消える |

### 注意事項

- 原作作品の固有名詞（キャラ名・組織名・技名・地名）は使用していません。
- 「凪」は一般語としての静寂の象徴として使用しています。
- 本セリフ集はオリジナル創作物として、キャラクター類型（寡黙で自虐的な水の剣士）の性格特性を参考に書き下ろしたものです。
