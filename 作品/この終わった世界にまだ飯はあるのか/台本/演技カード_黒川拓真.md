## 演技カード: この終わった世界にまだ飯はあるのか 第1話 / 黒川 拓真（藤 優真）

- 狙い: 笑いは周囲に任せる。拓真は場の温度を下げ、勘定し、最後に飯で着地する。
- 声の置き所: ミドル〜ロー。抑制ベース。張り上げない。
- 話体: **ルリエル相手はため口の呆れツッコミ**。町人・ギルド相手は普通の敬語。怒鳴らないので、ため口でも声量は抑える。熱の瞬間だけ芯が出る（「最悪だ」「……終わった」「ある。まずいけど、ある」）。
- 間: ルリエルのボケの直後に重ねない。**半拍置いてから、短い一句で刺す**。「あ。」「あ？」の掛け合い、店主の沈黙、倉庫の水没後の沈黙は、間そのものが笑いなので急がない。
- 対ルリエルの型: 「待て」「やめろ」「なんだよそれ」「全部、あんたのせいだ」。有能アピールには、事実だけ返す。原作の決まり文句は使わない。
- 解放ポイント:
  1. 「特典の中身が、女神か／最悪だ」——呆れの熱。叫びではない。
  2. 「神を信じるのは、やめた。俺が信じるのは、飯だ」——倉庫。初めて正面から切る。
  3. 「ある。まずいけど、ある」——締め。温かい。笑っていない顔で言う。
- NG: ハイテンション少年、毎打席の大声ツッコミ、物真似、説明口調の独白。原作の決まり文句。

### 第1話の尺

約20分。焔華・リディは出さない。二人の門出と、峠のフックまで。

### 温度の地図

| 区間 | 温度 | 注意 |
|---|---|---|
| 独白・現代 | 常温。人生の棚卸し | 自虐を売りにしない。事実を置く |
| 白の空間 | 冷たい客 | 神を崇めない。見積もりを取る |
| 噴水〜ギルド | 疲労 | 衛兵には普通の市民の声 |
| 倉庫 | 抑制→一句だけ熱 | 水音のあとで切る |
| 焔華・リディ | 採用面接 | 能力を値踏む。いじめない |
| 「飯はある」 | 唯一のぬくもり | すぐ次回フックへ戻さない。スープのSEを残す |

### 対比

- ルリエル: 高い。拓真は一段下げて、丁寧に返す。
- 焔華: 断定が長い。拓真は短い一文で折る。「麦です」の一言だけで返す箇所は、説明を足さない。
- リディ: 上品な敬語で下品なことを言う。拓真は乗らず、事実だけ確認する。
- ミラ: 同じ事務側。値切りの「七十」の応酬は、二人とも無表情でテンポよく。

### 笑いの設計（演出側で守るもの）

| 型 | 場所 | 演じ方 |
|---|---|---|
| 遅すぎる注意 | 作業員「あー、そこ、まだ蓋してないんですよ」 | 焦らない。世間話の声で言う |
| 天丼（せいっ→止める） | 噴水・パン・宿・ギルド・倉庫・広場 | 拓真の止め方を毎回変える。声量は上げない |
| 長い前置き→しょぼい落ち | 焔華の詠唱、名乗り | 名乗りは全力。拓真の「名刺、ありますか」は事務の声 |
| 反省しないボケ | ルリエル全般 | 一度も悪いと思わない。最後まで自分は有能 |
| 事務処理オチ | ミラ、衛兵「今週三人目」 | 笑わない。台帳を読む声 |
| 前フリ回収 | 面接／ネット／電柱 | 独白で回収する時、勝ち誇らない。静かに置く |

### 直した言い回し（旧版からの変更）

- 「特技は文句と、朝を迎えないこと」→ 「苦手なことは朝起きること」。死の予告に聞こえる曖昧さを削除。
- 体言止めの連打（「付ける。払う。払えるかは、後で」等）を主語述語のある文へ。ツッコミは**具体的な一文**で言い切る。
- 拓真の話体をため口から敬語基準へ統一し、熱の瞬間だけ崩す。

### 生声と心の声

台本の「拓真(M)」はナレーションではない。**拓真本人の心の声（Monologue）**。別役・別ナレーターは立てない。

- 生声（拓真：）：相手に聞こえる。敬語ツッコミ。落下の「あっ。」は短く、叫ばない。
- 心の声（拓真(M)：）：マイクを近づける。生声より遅く、すこし低い。笑いは乗せない。笑いは生声の短い一句にだけ乗せる。

### ベンチマーク

櫻井孝宏の抑制。必要な瞬間だけ熱。間とブレスも演技。コメディの軸は「怒鳴らない大人」。
